## 🎯 О проекте

Лендинг выполнен в современной тёмной urban-эстетике по дизайн-шаблону:

| Параметр | Значение |
|---|---|
| Фон | `#121212` / карточки `#1E1E1E` |
| Основной акцент | `#2563EB` (синий) |
| CTA-акцент | `#FF5722` (оранжевый) |
| Текст | `#FFFFFF` / вторичный `#A1A1AA` |
| Заголовки | **Anton** (капс, аналог Impact) |
| Текст | **Inter** |

Фирменные приёмы: секции с **рваными краями** (SVG), **неоновые обводки**, **фото-коллажи** с повёрнутыми бейджами, секция **тарифов** (PART 1 / PART 2 / PART +).

## 📑 Секции страницы

1. **Шапка** — логотип, 3 компактных пункта меню, кнопка звонка (с номером при наведении), CTA «Пробный урок»; на мобильных — бургер-меню с полным списком разделов.
2. **Hero** — бейдж, крупный заголовок `ENGLISH ROOM BY DREAMBUILDERS`, коллаж фото, бейдж «IELTS 7.0+», статистика.
3. **Что ждет** — 6 карточек методики (разговорная практика, международная литература, группы, игры, KZ/RU, контроль прогресса).
4. **Почему мы** — синяя секция с рваными краями и 6 преимуществами.
5. **О центре** — фото-коллаж + список выгод (бесплатная диагностика, первый урок 0 ₸, скидка «Приведи друга»).
6. **CTA-баннер** — призыв записаться на пробный урок.
7. **Тарифы** — 3 программы: PART 1 (Английский), PART 2 (IELTS, выделенный), PART + (всё включено) + чипы других направлений.
8. **FAQ** — аккордеон на 5 вопросов (синяя секция с рваными краями).
9. **Форма заявки** — имя, телефон, направление, комментарий, согласие.
10. **Контакты** — адрес, телефоны, график + карта Google Maps.
11. **Футер** — навигация, контакты, копирайт.

## ⚙️ Технологии

- **HTML5** — семантическая разметка, доступность (`aria-label`, `aria-expanded`, `alt`)
- **CSS3** — переменные, Grid/Flexbox, адаптив (2 брейкпоинта), анимации `reveal`
- **JavaScript (ES6+)** — без зависимостей: маска телефона, валидация, аккордеон, меню
- **Google Fonts** — Anton + Inter
- **Картинки** — Unsplash (CDN)
- **Карта** — Google Maps embed

## ▶️ Запуск локально

```bash
# Клонировать репозиторий
git clone https://github.com/Aleksandr-pro/DB-landing.git

# Перейти в папку
cd DB-landing
```

Откройте `index.html` двойным кликом **или** запустите локальный сервер:

```bash
# Вариант 1: Python
python -m http.server 8000
# → http://localhost:8000

# Вариант 2: Node.js
npx serve .
```

## 📨 Форма заявок

Форма работает в **демо-режиме без бэкенда**:

1. Валидирует данные на клиенте (имя, телефон в формате KZ, направление, согласие).
2. Сохраняет заявку в `localStorage` ключ `db_requests`.
3. Открывает почтовый клиент с готовым письмом на `dreambuilders.edu@gmail.com`.

**Для боевой эксплуатации** замените отправку в `script.js` на один из вариантов:

```js
// Вариант A: Formspree (бесплатный тариф)
await fetch('https://formspree.io/f/ВАШ_ID', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data),
});

// Вариант B: Web3Forms (бесплатно, ключ с сайта)
await fetch('https://api.web3forms.com/submit', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ access_key: 'ВАШ_КЛЮЧ', ...data }),
});
```
